# Cold-chain incident report

Consignment DBATCH-010 of Basalog 100 IU/ml (batch BATCH-A009, pack code MED-ASALI-009) left the 2.0-8.0 C band for 2 logged interval(s); peak 14.8 C.

## Impact

Temperature-sensitive product. The receiving pharmacy VND-003 was asked to quarantine the units pending a stability assessment by the manufacturer MFG-004.

## Corrective action

Vehicle AI-864 withdrawn from cold-chain duty; refrigeration unit to be serviced; driver retraining scheduled.
