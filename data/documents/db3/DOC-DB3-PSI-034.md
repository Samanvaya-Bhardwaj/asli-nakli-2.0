# Product safety information: Omeprazole

Therapeutic class: antacid; ATC A02BC01; schedule OTC.

Marketed as: Omevane 20mg, Omez 20mg.

## Storage

Store below 25 C in a dry place, protected from light.

## Safety

Report suspected adverse reactions to the pharmacovigilance programme. Check the pack's printed code and hologram; buy only from licensed pharmacies.
